# 👋 getto-dev

Создаю прикладные веб-приложения и PWA, которые решают конкретные практические задачи.

---

## 🚀 Приложения

### 🧾 СметаПро

**Строительные сметы**

Приложение для быстрого составления смет на работы и материалы. Каталог позиций, расчёт стоимости, скидки, сохранение, экспорт и работа в офлайн-режиме.

[**Открыть приложение**](https://getto-dev.github.io/smeta/) · [**GitHub**](https://github.com/getto-dev/smeta)

---

### 🔧 СантехСчёт

**Сметы на сантехнические работы**

PWA-калькулятор для составления, расчёта и выгрузки смет прямо на объекте. Каталог сантехнических работ и материалов, пользовательские позиции и PDF-экспорт.

[**Открыть приложение**](https://getto-dev.github.io/check/) · [**GitHub**](https://github.com/getto-dev/check)

---

### 🌱 Садовод

**Справочник садовода**

PWA-справочник с каталогом культур, информацией по выращиванию и уходу, статьями и поиском.

[**Открыть приложение**](https://getto-dev.github.io/garden/) · [**GitHub**](https://github.com/getto-dev/garden)

---

### 💧 Прайс-лист

**Сантехнические работы**

PWA-прайс-лист с каталогом услуг и ценами, который можно использовать как быстрый справочник на телефоне или компьютере.

[**Открыть приложение**](https://getto-dev.github.io/price/) · [**GitHub**](https://github.com/getto-dev/price)

---

### 🏠 Home Page

**Новая вкладка для Chrome**

Chrome-расширение для отображения закладок на новой вкладке браузера.

[**GitHub**](https://github.com/getto-dev/home-page)
